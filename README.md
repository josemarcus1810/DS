# Sistema de Almoxarifado

O Sistema de Almoxarifado foi desenvolvido para facilitar o controle e a organização dos materiais, permitindo acompanhar produtos, quantidades, lotes, pedidos de compra e movimentações em um só lugar.

A ideia é tornar o gerenciamento do estoque mais simples, organizado e acessível para os usuários.

## Acesse o sistema

**Link:** https://dssistema-almoxarifado.onrender.com

O sistema funciona diretamente pelo navegador, sem precisar instalar programas ou executar arquivos no computador.

## Como fazer login

1. Acesse o link do sistema.
2. Informe seu usuário e sua senha.
3. Clique em entrar.
4. Após a autenticação, você será direcionado à página inicial.

Os dados de acesso devem ser fornecidos pelo administrador do sistema.

## Conhecendo as funcionalidades

O sistema possui um menu lateral com as principais áreas:

### Início
É a página inicial do sistema, onde o usuário pode começar a navegação e acessar as demais funcionalidades.

### Produtos
Permite cadastrar e consultar os produtos armazenados no almoxarifado.

Durante o cadastro, são informados dados como:
- Nome do produto;
- Tipo;
- Data de validade;
- Quantidade.

Cada produto recebe um código de identificação gerado pelo sistema.

### Lotes
Permite registrar e acompanhar os lotes vinculados aos produtos cadastrados.

É possível consultar informações como número do lote, quantidade, validade e situação.

### Pedidos de compra
Área destinada ao registro e acompanhamento das solicitações de compra de materiais.

Os pedidos possuem informações como produto, quantidade, setor solicitante e link de referência, além de um status para acompanhar sua situação.

### Movimentações
Reúne o histórico das alterações realizadas no estoque, ajudando a acompanhar inclusões, edições, exclusões e novos lotes.

### Usuário
Área destinada às opções de gerenciamento de usuários, conforme as permissões do perfil de acesso.

O administrador possui acesso às funções de gerenciamento de usuários e às demais áreas administrativas do sistema.

### Sair
Encerra a sessão do usuário. É recomendado utilizar essa opção ao terminar de acessar o sistema, principalmente em computadores compartilhados.

## Perfis de acesso

O sistema trabalha com diferentes níveis de acesso:

- **Administrador:** possui acesso completo às funcionalidades administrativas e ao gerenciamento dos usuários.
- **Colaborador:** possui acesso às funcionalidades disponibilizadas de acordo com suas permissões.

## Algumas recomendações

- Confira as informações antes de cadastrar ou editar um produto.
- Verifique as datas de validade para evitar registros incorretos.
- Utilize os lotes para manter o controle dos materiais.
- Consulte o histórico de movimentações sempre que precisar acompanhar alterações.
- Não compartilhe sua senha com outras pessoas.
- Ao finalizar o uso, lembre-se de sair da sua conta.

## Considerações finais

O Sistema de Almoxarifado foi pensado para centralizar informações e facilitar as atividades de controle de estoque.

Como o acesso é feito pela internet, os usuários podem utilizar o sistema pelo navegador, sem depender da execução local do projeto.
